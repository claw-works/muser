# 效果器：flanger

镶边：极短延迟的调制，产生金属感的扫动（喷气机声）。

**放在哪里**：适合合成器、吉他、鼓的点缀段落；放在混响之前，通常不长时间整首使用。

查看最新参数：`muser effects flanger`（MCP：`describe_effect`）

## 参数

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `rate_hz` | 0.2 | 0 – 100 Hz | 扫动速度。0.1-0.3 慢扫；>1 快速颤动 |
| `feedback` | 0.7 | -0.95 – 0.95 | 谐振强度。越大金属感越强 |
| `mix` | 0.5 | 0 – 1 | 干湿比。0.5 效果最明显 |

所有参数都可省略，省略时取默认值；超出范围时 `muser validate` 会报出具体位置。

## 最小示例

```json
{ "type": "flanger", "rate_hz": 0.2, "feedback": 0.7, "mix": 0.5 }
```

## 场景预设

- 慢扫喷气机（过渡段）

  ```json
  {"type": "flanger", "rate_hz": 0.15, "feedback": 0.7, "mix": 0.5}
  ```

- 轻微金属着色

  ```json
  {"type": "flanger", "rate_hz": 0.3, "feedback": 0.4, "mix": 0.35}
  ```

## 经验与常见错误

- 效果很强烈，适合点缀段落或单独的轨，不建议整首都开在主旋律上。
- feedback 接近 0.95 时谐振非常尖，注意音量。
